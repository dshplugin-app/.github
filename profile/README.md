# DSH Plugin Registry

**Discover, compare, and evaluate DeepSeek Harness plugins.**

DSH Plugin Registry is an independent directory for the DeepSeek Harness plugin ecosystem, combining plugin discovery with source-backed repository intelligence.

## Explore DeepSeek Harness Plugins

- **Plugin Directory** — Browse and search DeepSeek Harness plugins by category, type, verification status, and repository activity.
- **Repository Intelligence** — Understand plugin capabilities using source-backed repository analysis.
- **Security Signals** — Review objective signals from package metadata, manifests, dependencies, and lifecycle scripts.
- **Compatibility Evidence** — Check version-specific runtime evidence and tested or untested combinations.
- **Install Information** — Find install commands, target profiles, repository sources, and related plugin information.
